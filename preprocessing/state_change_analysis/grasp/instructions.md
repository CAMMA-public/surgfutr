# GraSP Clip Preparation

This folder contains scripts for preparing GraSP frame based video clips for state change analysis and for RSD, Phase and Step transition tasks.

1. 📝 Run `get_state_change_steps.py` to generate a JSON file containing frame based video clips for state change learning on steps.

2. 📝 Run `get_anticipation_labels.py` to generate a JSON file containing frame based video clips for RSD, Phase and Step Transition.
